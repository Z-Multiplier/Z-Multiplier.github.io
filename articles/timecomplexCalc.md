# 时间复杂度计算器

这里是一个数据范围到复杂度的映射表

|数据范围|复杂度|典型算法|
|:--:|:--:|:--:|
|$n \le 20$|$O(n!)$|全排列枚举等|
|$n \le 20$|$O(2^n)$|状压dp等|
|$n \le 100$|$O(n^3)$|`Floyd`，$n^2\times n$算法等|
|$n \le 1000$|$O(n^2)$|区间枚举等|
|$n \le 10000$|$O(n \sqrt{n})$|根号分治，莫队等|
|$n \le 100000$|$O(n \log n)$|倍增，树状数组等|
|$n \le 1000000$|$O(n)$|双指针等|
|$n \le 10^{18}$|$O(\log n)$|数学/单次倍增|
|$n \le 10^{any}$|$O(1)$|数学|
