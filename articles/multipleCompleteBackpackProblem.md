# U591180 鸡蛋三明治

## 题目描述

小K爱吃鸡蛋三明治，他的冰箱里有$a$个鸡蛋和$b$片面包，小K一共知道$n$种三明治食谱，只要材料足够，就可以无限制作，它们分别需要$x_i$个鸡蛋,$y_i$片面包，且它们的美味程度分别为$z_i$，现在小K想知道，该怎么分配鸡蛋和面包，才能让获得的美味程度之和最大.

## 输入格式

输入共$n+1$行，第一行包含三个数$a,b,n$\
接下来$n$行，每行包含三个数$x_i,y_i,z_i$，含义如题所示

## 输出格式

输出包含一个数，表示美味程度之和的最大值

## 输入输出样例 #1

### 输入 #1

```
2 2 3
1 1 2
1 2 1
3 2 1
```

### 输出 #1

```
4
```

## 输入输出样例 #2

### 输入 #2

```
1 1 5
2 2 1
2 3 1
3 3 1
3 4 1
4 4 1
```

### 输出 #2

```
0
```

## 说明/提示

对于$20\%$的数据，有$x_i=y_i=1$\
对于全部数据，有$a,b,n\le10^3$\
$x_i,y_i,z_i\le2\times10^2$
